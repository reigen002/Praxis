# Praxis

Desktop React dashboard for founders reviewing operational priorities, with a
local FastAPI seam into a Python/CrewAI service. Streamlit remains a legacy entry
point. The demonstration audience is an AI Generalist internship reviewer.

Success is a sourced briefing from exactly two real sequential agents, followed
by evidence inspection and a local review decision. Python owns metrics and
mandatory policy. JEV optionally supplies a bounded signal for one selected
record, with saved genuine responses reused to conserve credits.

All business data is synthetic, with an explicit reference date. Facts, judgments
and proposed actions must be distinguishable. No external actions exist. Rules
and source records remain useful without model access; never simulate a live run.
